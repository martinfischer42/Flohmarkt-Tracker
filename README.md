# Flohmarkt Tracker

Kleine Offline-Web-App zum Erfassen verkaufter Flohmarkt-Artikel.

## Funktionen

- Foto eines verkauften Artikels aufnehmen oder auswählen
- Verkaufspreis speichern
- optionalen Artikelnamen ergänzen
- Anzahl, Gesamtumsatz und Durchschnittspreis anzeigen
- CSV exportieren
- JSON-Backup inklusive Fotos exportieren

## Nutzung

Die App besteht aus einer einzelnen `index.html` und kann direkt im Browser geöffnet
oder über GitHub Pages veröffentlicht werden.

Die Verkäufe werden lokal im Browser gespeichert. Nach dem Flohmarkt sollte über
`Backup exportieren` eine Sicherung erstellt werden.
